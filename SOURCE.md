# Источник данных и литература

Дата проверки источников: 9 ноября 2026 года.

## Корпус

**Ilya Gusev, Gazeta.** [Репозиторий автора](https://github.com/IlyaGusev/gazeta), [публикация](https://arxiv.org/abs/2006.11063), [раздача автора на Hugging Face](https://huggingface.co/datasets/IlyaGusev/gazeta).

Gazeta создан для реферирования русских новостей. В выбранной раздаче train содержит 60 964 записи: `text`, `summary`, `title`, `date`, `url`. В этом эксперименте единицей анализа служит **только поле `summary`**, редакционная краткая аннотация. Модель и участник получают одну и ту же нормализованную строку; заголовок и полная статья не входят в её вход. В репозиторий включены отобранные аннотации. Исходные страницы с полными статьями повторно загружаются при формировании новой выборки.

Получение: публичный API Dataset Viewer, `https://datasets-server.huggingface.co/rows`, dataset `IlyaGusev/gazeta`, config `default`, split `train`. Сохраняются 20 случайных полных страниц по 100 строк. После фильтра длины 150–650 символов, доли кириллицы и точного удаления нормализованных дубликатов из пула случайно выбираются 1000 текстов. Все seed, номера страниц и фактические размеры есть в `data/manifest.json`. Последние 64 записи неполной страницы в рамку выборки не входят.

Это двухступенчатая выборка страниц, затем текстов, а не простая равновероятная выборка из всего train. Соседние новости могут быть зависимы по времени и теме. Близкие по смыслу дубликаты автоматически не исключались; точные совпадения исключены. Такая выборка удобна для учебного локального опыта, но не обеспечивает представительность всей русской речи. Данные получены через публичный API без учётной записи Kaggle.

Автор корпуса указывает некоммерческое использование и принадлежность прав Газете.ru; карточка Hugging Face показывает `license: unknown`. Здесь не приписывается корпусу лицензия MIT/CC. Сохраняются ссылки на первоисточники; проект предназначен для учебной работы. Основание и формулировки автора: раздел Additional notes в репозитории.

## Почему выбран такой формат смысла

1. **Novak, J. D.; Cañas, A. J. (2008). The Theory Underlying Concept Maps and How to Construct and Use Them.** [Оригинальный отчёт IHMC](https://cmap.ihmc.us/docs/pdf/TheoryUnderlyingConceptMaps.pdf). Концептуальные карты представляют понятия узлами, отношения — подписанными связями. Отсюда взята форма понятной человеку направленной связи; сложная иерархическая карта целиком не воспроизводится.

2. **Banarescu et al. (2013). Abstract Meaning Representation for Sembanking.** [ACL Anthology](https://aclanthology.org/W13-2322/). Показывает, как смысл можно записывать графовой структурой. Наши русские связи существенно проще: нет фреймового словаря, полного разбора и графового выравнивания AMR. Поэтому работа не называет свой формат AMR и не считает Smatch.

3. **Mihalcea, R.; Tarau, P. (2004). TextRank: Bringing Order into Text.** [ACL Anthology](https://aclanthology.org/W04-3252/). Графовые методы позволяют ранжировать единицы текста на основе связей. Это контекст выбора графового представления. TextRank в коде не реализуется; лексическая точка сравнения здесь — TF–IDF биграмм/триграмм. Их совместная встречаемость не эквивалентна семантическому отношению.

4. **Artstein, R.; Poesio, M. (2008). Inter-Coder Agreement for Computational Linguistics.** [ACL Anthology](https://aclanthology.org/J08-4004/). Обосновывает необходимость учитывать постановку разметки и ограничения мер согласия. При одном человеке нельзя оценивать межчеловеческое согласие. Cohen κ здесь допускается только как дополнительная описательная мера человек–машина по общим бинарным решениям; основной результат — F1, FP/FN и интервалы по текстам.

5. **Gilardi, F.; Alizadeh, M.; Kubli, M. (2023). ChatGPT Outperforms Crowd-Workers for Text-Annotation Tasks.** [Авторская публикация](https://arxiv.org/abs/2303.15056). Даёт пример эмпирического сравнения LLM с человеческой разметкой. Результаты чужой модели и чужих задач нельзя переносить на Qwen и русский корпус без собственной проверки.

6. **Gusev, I. (2020). Dataset for Automatic Summarization of Russian News.** [Авторская публикация](https://arxiv.org/abs/2006.11063). Источник описания Gazeta, а не доказательство качества извлечения смысла в данном эксперименте.
